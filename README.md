# SpiceWala

Multi-page Indian spices e-commerce (B2B + B2C) built with React + Vite + TypeScript.

**Brand identity:** spices as pigment — roasted-espresso base, Fraunces / Work Sans / IBM Plex Mono, and a consistent pigment swatch system (turmeric gold, chili brick, cardamom olive, saffron ember…).

## Run

```bash
npm install
npm run dev
```

## Features

- Full catalogue with filters, search, product detail (zoom, packs, MOQ, RFQ)
- Cart, coupons, guest/login checkout, multi-payment UI
- Currency selector (INR base → USD/GBP/AUD/CAD/EUR/AED) + language switcher
- Wishlist, account, order tracking (localStorage)
- B2B: Export, Private Label, Bulk/RFQ, Distributor
- About, Certifications, Blogs, Gallery, FAQ, Contact, Admin demo
